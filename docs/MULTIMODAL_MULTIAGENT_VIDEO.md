# Dola Seed Studio — Multimodal Video Agent Skills

## Vision
Images, videos and documents are production evidence. The agent must inspect them before making creative or timeline decisions when they are available.

## Character continuity
Each character receives a stable ID. Maintain face/appearance, wardrobe, props, blocking, gaze, screen direction and interaction state across scenes.

## Multi-character scenes
Build a character map and staging plan before generating a scene with multiple characters. Keep spatial relationships explicit.

## Image creation
Support concept frames, character sheets, location sheets, keyframes, style frames, props and reference-conditioned image generation.

## Video creation
Support text-to-video, image-to-video, reference-to-video, first/last-frame workflows, video extension and targeted video editing through Seedance.

## Layered timeline editing
Treat video, character composites, dialogue, music, SFX, captions, overlays, masks and transforms as independent reversible layers.

## Multi-agent production
Route work through director, vision, character continuity, world continuity, storyboard, editor, audio and QA roles. Do not regenerate approved unaffected shots.

## Model routing
Use DeepSeek V4.1 Flash for visual/deep analysis, GLM 5.3 Flash for multimodal continuity/tool work, and Dola Seed 2.1 Turbo for directing and timeline orchestration. Current ModelArk documentation lists these models and capabilities.
