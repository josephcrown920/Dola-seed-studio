# Dola Seed Studio 2.1 Pro
All-in-one cross-platform desktop AI creative workstation integrating Dola Seed 2.1 LLM, Seedream 5.0 image generation engine, and professional motion-controlled AI video editing.

---

## ✨ Core Features

### 🧠 Dola Seed 2.1 AI Assistant
- 4 model tiers: Pro / Lite / Mini / Code
- Full multimodal support: text, images, video input (drag-and-drop upload)
- Built-in capabilities: script writing, code generation, image/video analysis, multi-step agent workflows
- One-click send prompts/script directly to Seedream 5.0 or the video editor

### 🖼️ Seedream 5.0 Image Generation
- 3 official model tiers: Pro / Lite / Pro Max (4K resolution support)
- 3 working modes: Text-to-Image, Image-to-Image, semantic inpainting
- Exclusive Seedream 5.0 features: real-time web search, deep reasoning mode, enhanced text rendering, character consistency, multilingual support
- Built-in style presets, persistent generation history gallery, one-click export to video motion pipeline

### 🎮 Professional Motion Control System
- Visual keyframe editor: click directly on reference images to draw custom camera motion paths
- 8 pro camera presets (one-click apply): zoom in, zoom out, pan left/right, tilt up/down, orbit, dolly zoom
- Advanced controls: motion intensity slider, AI subject tracking, depth-of-field simulation
- Fully integrated with the image-to-video generation pipeline

### 🎬 AI Video Editor (Seedance 2.1 Engine)
- Two generation modes: Text-to-Video, Image-to-Video (paired with motion control)
- Professional 4-track timeline (video / audio / subtitle / effects)
- AI editing toolkit: beat-based auto-cut, automatic multilingual subtitles, 4K super resolution, smart frame interpolation, style transfer, character consistency preservation
- Multiple export options: MP4, MOV, WEBM, GIF, PNG sequences
